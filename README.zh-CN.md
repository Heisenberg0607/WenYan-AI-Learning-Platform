# 基于大模型微调与语义检索的文言文学习平台

[English](README.md) | [한국어](README.ko.md) | [简体中文](README.zh-CN.md)

《文本挖掘技术》课程项目，通过 FastAPI 集成 GPT-4o-mini 微调模型与 BERT 语义检索，为中学生文言文学习提供辅助。

## 项目概览

### 问题定义

中学生在学习文言文时，常面临词义理解困难、无法凭不完整的记忆找到诗句等问题。断句与翻译练习也需要及时反馈，因此本项目旨在通过一个平台支持这些学习活动。

### 解决方法

分别使用 WenyanGPT 的 19,644 条样本和 WenyanBench Translation 的 5,013 条样本，对 GPT-4o-mini 进行断句与翻译任务的监督微调。针对 910 条古诗文构建 BERT-Ancient-Chinese 语义检索，并结合 BERT-Base-Chinese 与基于规则的实体、关系抽取实现词义解释评分，最终通过 FastAPI 集成各项功能。

### 成果用途

用户可以为无标点文言文添加标点、将文言文翻译为现代汉语，并检索与输入诗句语义相近的作品。在“猜猜注释”中，用户可以根据上下文解释词义，查看与标准答案的对比及自动评分反馈。

## 数据与预处理

| 数据 | 规模 | 构成与用途 |
| --- | ---: | --- |
| WenyanGPT 句逗数据 | 19,644 条 | 预处理后划分为 18,000 条训练样本与 1,644 条验证样本 |
| WenyanBench Translation | 5,013 条 | 文言文原文与现代汉语译文的平行样本 |
| 网页采集古诗文数据 | 910 条 | 包含标题、作者、朝代、正文、翻译、注释等元数据，由检索与猜猜注释共享 |

断句数据先整理为 instruction、input、output 结构，并纳入多种指令表述。随后转换为基于 messages 的 JSONL，以 system、user、assistant 角色分别组织任务要求、原文与标准输出。

翻译数据使用相同的对话式 JSONL 结构。system 包含翻译要求，user 提供文言文原文，assistant 提供对应的现代汉语译文。

## 方法与系统结构

### 1. 面向不同任务的 GPT-4o-mini 监督微调

断句任务被定义为给原文补充适当的标点符号。报告说明，选择监督微调是为了让模型适应所需的输出格式与标点插入规则。

翻译任务使用文言文与现代汉语平行数据，单独微调模型。保留原文含义和信息、保持译文表达一致性是其设计目标。两项任务均使用 OpenAI fine-tuning API。

### 2. BERT-Ancient-Chinese 语义检索

根据检索语料的语言特点，选择在古汉语语料上预训练的模型。系统对古诗文进行滑动窗口切分，通过均值池化构建嵌入，并计算查询向量与候选向量之间的余弦相似度。

报告描述，将整篇作品表示为单一向量时，难以定位与短查询对应的具体语句，因此探索了半句、一句和两句的切分粒度。最终以标点为边界构建重叠片段，并按长度存入 Window_1~Window_4。

系统根据查询中的标点数量选择向量仓库，在相似度最高的候选结果中去除同一作品的重复项，返回来自不同作品的 Top-K 结果。

### 3. 词义解释评分

题目从 910 条古诗文数据的注释中随机选取。对用户答案与标准答案使用 Jieba 分词、词性标注、以名词为主的候选提取，以及停用词、长度过滤和规则来构建实体。

关系抽取使用“定义”“属性”“地理位置”等 8 类预定义模式。BERT-Base-Chinese 将提取的实体表示为 768 维向量，用于计算语义相似度。

- **实体匹配：** 为每个标准实体选择最相似的用户实体，余弦相似度不低于 0.7 时视为有效匹配。
- **关系错误：** 当关系类型相同、主语相似度不低于 0.7、但宾语相似度低于 0.7 时，判定为错误。
- **总分：** 有效匹配相似度的平均值 × 100 − 关系错误数量 × 15 分。最低分为 0 分，达到 70 分时判定为“正确”。

### 4. 平台集成

通过 FastAPI 集成断句、翻译、语义检索与猜猜注释。学习者可以通过输入原文、查看结果、填写答案和查看评分反馈完成相应学习活动。

报告中的查询与返回结果示例可以展示语义检索的运行情况。量化评价需要构建带有相关性标注的查询集，并使用 Precision、Recall 等指标衡量。

词义解释评分界面的 94.5/100 分是为一条用户答案计算的分数。评分系统自身的准确率及其与人工评价的一致程度，需要另行评价。

## 局限与改进方向

- **泛化评价：** 断句的 96.8% 为训练准确率。需要在独立评价数据上使用断句边界指标与错误分析，确认实际输入下的表现。
- **翻译质量评价：** 需要补充对含义保留、信息遗漏、表达适当性的评价标准与人工审阅。
- **检索范围：** 按查询长度选择单一窗口仓库，可能遗漏其他长度片段中的相关结果。多窗口检索与词汇、向量混合检索是后续考虑方向。
- **检索使用体验：** 报告指出存在模型首次加载延迟，以及对现代汉语查询支持有限的问题。
- **评分规则：** 实体与关系抽取依赖规则，处理特殊表达、典故与复杂同义表达时需要完善规则。
- **个性化学习：** 在现有随机出题基础上结合难度信息与学习历史，是后续改进方向。
